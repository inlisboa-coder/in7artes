# Gravuras inLisboa — Arte Portuguesa e Lisboa

Galeria pública das obras da inLisboa.com, organizadas em colecções.

- Todas as imagens têm marca de água InLisboaArt. Os ficheiros originais não estão neste repositório.
- Sem preços nem compra nesta fase: cada obra tem os botões «Pedir este produto» e «Pedir informação», que preparam um email para inlisboa@gmail.com com a referência do formato escolhido.
- Formatos: papel (sem moldura / emoldurado), tela (desenho em tela / em engradado / emoldurada), ficheiro digital (A4, A3, A3+, conforme a resolução) e original.

Fase seguinte: integração no in7artes com pedidos guardados, produtos no Shopify e pagamento só cobrado após confirmação.
